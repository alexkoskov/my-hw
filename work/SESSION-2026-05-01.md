## Risk notes

- **Wave 1** is pure file deletion of unused scripts. Zero prod risk.
- **Wave 2-4** removed dead-only-by-tests code paths in `news_bot.py`
  (`translate_text`, `_fallback_publish_google_only`, `build_admin_ping`)
  and consolidated `load_feeds()` error handling into a helper. No behaviour
  change in any reachable code path.
- **Wave 5** is structural refactor on the auto-publish hot path. Behaviour
  preserved per all tests. The four engine modules now share the same
  `_llm_common._parse_response` body, parametrised by engine name (used in
  error message text + WARNING logs) and logger.
