# Task 5: Fallback orchestrator

## Description

Implement `fetch_facebook_posts(config)` that tries RSS, Graph API, HTML in order (skipping unavailable methods), applies keyword filtering, and returns list of uniform entries. Respect rate limits between requests.

## What to do

1. Implement `fetch_facebook_posts(config)`:
   - Receive a configuration dictionary (from `load_config`) containing `page_url`, `filter_keywords`, `enabled`, `method_priority`, and optional `access_token`.
   - If `enabled` is `False`, return empty list immediately.
   - Iterate over `method_priority` (default: `["rss", "graph_api", "html"]`):
     - For `"rss"`: call `fetch_facebook_rss(page_url)`
     - For `"graph_api"`: if `access_token` present, call `fetch_facebook_graph(page_id, access_token)` (extract page ID from URL); else skip.
     - For `"html"`: call `fetch_facebook_html(page_url)`
   - After each attempt, if the returned list is non‑empty, stop iterating and proceed to filtering.
   - If a method fails (exception or empty result), log the error and try the next method.
   - Between method calls, respect rate limits (e.g., sleep 2 seconds for Graph API, optional for others).

2. Apply keyword filtering:
   - Pass the retrieved posts through `filter_posts_by_keywords(posts, config['filter_keywords'])`.

3. Format entries:
   - Map each filtered post via `format_facebook_entry(post)` to produce uniform entries.

4. Return the list of uniform entries (could be empty if all methods fail or all posts filtered).

## Details

**Files:** 
- `facebook_source.py` — add `fetch_facebook_posts` function

**Dependencies:** Tasks 1‑4 (configuration, RSS, Graph API, HTML, filtering, formatting)

**Edge cases:**
- All methods fail → returns empty list, logs error
- `method_priority` contains unknown method → skip with warning
- `access_token` present but invalid → Graph API fails, fallback to HTML
- RSS returns empty list (no posts) → treat as failure? (spec may treat as success with empty list, but fallback may still be desired)
- Filter keywords empty → no filtering

**Implementation hints:**
- Use a loop over `method_priority`; for each method call the corresponding function inside a try‑except.
- Extract page ID from URL: `page_url.rstrip('/').split('/')[-1]`.
- Use `time.sleep` for delays; consider making delays configurable.
- Log each attempt with level INFO/ERROR.
