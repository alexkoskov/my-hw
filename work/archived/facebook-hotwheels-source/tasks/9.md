# Task 9: Integration tests

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Write integration tests that simulate the full pipeline: load config, fetch Facebook posts (mocked), feed into `process_new_articles` (mocked Telegram), verify translation, summarization, posting, and database marking.

## What to do

1. Create a new integration test file `tests/integration/test_facebook_pipeline.py`.
2. Write integration tests that cover the following scenarios:
   - **Full Facebook source integration**: load config, mock HTTP responses for RSS/Graph API/HTML, call `fetch_facebook_posts`, verify uniform entry format.
   - **Integration with existing pipeline**: feed mock Facebook entries into `process_new_articles` (with mocked `send_to_telegram` and `transcreate_text`), verify translation, summarization, and posting happen correctly.
   - **Database verification**: after processing a mock Facebook post, check that its link appears in the `processed_news` table (use test database).
   - **Error isolation**: simulate Facebook source failure (e.g., all methods fail), ensure admin notification sent and other RSS feeds continue.
   - **Keyword filtering integration**: posts containing keywords are filtered out before reaching the pipeline.
   - **Rate‑limiting behavior**: verify delays between Graph API calls (mocked).
   - **Backward compatibility**: run the pipeline without Facebook config, ensure existing RSS feeds still work.

3. Use pytest fixtures to set up a temporary SQLite database, mock external services (HTTP, Telegram), and clean up after each test.
4. Ensure tests are isolated (no real network calls) and can run in CI.
5. Run the integration test suite and verify no regressions in existing integration tests.
