## Required Skills

## Description

Live environment verification:
- Check that Facebook posts appear in Telegram channel (non‑event posts).
- Verify translation and hashtags are present.
- Monitor logs for errors.
Tools: Telegram MCP, curl, bash.

## What to do

1. **Monitor logs**:
   - Access production logs (e.g., `journalctl -u news-bot`, Docker logs, CloudWatch).
   - Look for errors related to Facebook fetching, translation, or Telegram posting.
   - Ensure no recurring failures.

2. **Verify Facebook posts in Telegram channel**:
   - Use Telegram MCP to read the latest messages from the target channel.
   - Identify posts that originate from Facebook (look for `#hotwheels #facebook` hashtags and Facebook link).
   - Verify that non‑event posts (e.g., announcements about new products) appear, while event posts (containing keywords) are filtered out.
   - Check that each post includes translation (if original English) and hashtags.

3. **Manual spot‑check**:
   - Pick a recent Facebook post from the Hot Wheels page (manually visit page) and see if it appears in Telegram.
   - If not, investigate why (filtered, fetching error, rate limit).

4. **Performance and stability**:
   - Ensure the bot schedule runs without hanging (check process uptime).
   - Verify that RSS feeds continue to be processed alongside Facebook.

5. **Document verification results**:
   - Write a post‑deploy verification report in `work/facebook-hotwheels-source/logs/qa/post-deploy-qa.md`.
   - Include screenshots or message excerpts as evidence.
   - Note any issues observed.

## Acceptance Criteria

- [ ] No critical errors in logs related to Facebook source
- [ ] At least one non‑event Facebook post appears in Telegram channel (if available)
- [ ] Facebook posts include translation (if English) and hashtags `#hotwheels #facebook`
- [ ] RSS feeds continue to work (no regression)
- [ ] Verification report written
