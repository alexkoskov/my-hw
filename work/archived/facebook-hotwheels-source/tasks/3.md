# Task 3: HTML parser for Facebook posts

## Required Skills

Перед выполнением задачи загрузи:

## Description

Implement `fetch_facebook_html(page_url)` that downloads public page HTML, extracts posts using BeautifulSoup selectors, and returns entries in same format. Handle missing elements gracefully.

## What to do

1. Implement `fetch_facebook_html(page_url)`:
   - Use `requests` to fetch the public Facebook page HTML (e.g., `https://www.facebook.com/hotwheels/`)
   - Parse HTML with `BeautifulSoup` (already in dependencies)
   - Identify post containers using CSS selectors (e.g., `div[data-testid="post_message"]`, `div[role="article"]`). Research current Facebook HTML structure.
   - For each post container extract:
     - Link: permalink URL (maybe `a[href*="/permalink/"]`)
     - Title: first 50 characters of post text (or empty)
     - Published date: timestamp from `abbr` or `time` element
     - Message: full post text (cleaned of extra whitespace)
     - Images: up to 2 image URLs from `img` elements inside the post
   - Map extracted data to uniform entry format (`link`, `title`, `published`, `message`, `images`)
   - Handle missing elements gracefully (e.g., if no date, use current time; if no message, empty string)

2. Ensure robust parsing:
   - Wrap extraction in try‑except to skip malformed posts
   - Log warnings when expected selectors fail
   - Respect Facebook’s rate limits: add a delay between requests (e.g., 2 seconds)

3. Return list of entries (could be empty if no posts found or parsing fails).

**Edge cases:**
- Facebook page requires login (returns login page) → detect login redirect, return empty list, log warning
- HTML structure changes (selectors fail) → fallback to alternative selectors, log error
- Posts with only images (no text) → message empty, images populated
- Posts with videos (ignore videos)
- Large HTML size → memory efficient parsing (use `lxml` parser)

**Implementation hints:**
- Use `requests.get` with `User‑Agent` header to mimic browser.
- Inspect real Facebook page HTML (offline) to determine reliable selectors.
- Consider using `lxml` parser for speed (already installed via beautifulsoup4).
