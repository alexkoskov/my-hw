# Task 1: Configuration schema and loader

## Required Skills

Перед выполнением задачи загрузи:

## Description

Create `facebook_source.json` configuration file with schema: page URL, access token (optional), filter keywords, enabled flag, method priority. Write loader function that reads and validates config, falls back to environment variables.

## What to do

1. Create a new configuration file `facebook_source.json` in the project root with the following schema:
   - `page_url` (string, required): Facebook page URL (e.g., `https://www.facebook.com/hotwheels/`)
   - `filter_keywords` (list of strings, optional): Keywords to exclude posts (default: `["event", "announcement", "coming soon", "glow‑n‑fire"]`)
   - `enabled` (boolean, optional): Whether Facebook source is enabled (default: `true`)
   - `method_priority` (list of strings, optional): Order of fetch methods (default: `["rss", "graph_api", "html"]`)

2. Implement `load_config()` function in a new module `facebook_source.py` that:
   - Reads `facebook_source.json` from the same directory as `news_bot.py` (or a configurable path)
   - Validates required fields and types
   - Falls back to environment variable `FACEBOOK_ACCESS_TOKEN` for the access token (if not present in config)
   - Returns a dictionary with the configuration values

3. Ensure the loader raises appropriate errors (e.g., `FileNotFoundError`, `json.JSONDecodeError`, `ValueError` for validation) with clear messages.

## Details

**Files:** 
- `facebook_source.py` (new) — implement `load_config()`
- `facebook_source.json` (new) — create configuration file

**Dependencies:** None (wave 1)

**Edge cases:**
- Config file missing → raise `FileNotFoundError` (or fallback to defaults)
- Malformed JSON → raise `json.JSONDecodeError`
- Missing required field (e.g., `page_url`) → raise `ValueError`
- Environment variable `FACEBOOK_ACCESS_TOKEN` not set → token field is `None`
- Duplicate configuration (both file and env) → prefer env? (design decision)

**Implementation hints:**
- Use `json.load` to read the file, `os.getenv` for environment variable.
- Consider using `jsonschema` for validation (optional).
- Keep the config loader simple; reuse patterns from `news_bot.py`'s `load_feeds`.
- The config path can be relative to the script location or absolute; decide based on existing project conventions.
