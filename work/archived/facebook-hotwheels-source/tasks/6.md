# Task 6: Integration into job()

## Required Skills

## Description

Modify `job()` in `news_bot.py` to load Facebook config, call `fetch_facebook_posts`, merge entries with RSS entries, add `feed_url` field, and pass through existing pipeline. Ensure error isolation (try‑catch around Facebook fetching).

## What to do

1. Modify `job()` function in `news_bot.py`:
   - After loading RSS feeds (`load_feeds()`), attempt to load Facebook configuration via `load_config()` (from `facebook_source.py`).
   - If Facebook config is present and enabled (`config['enabled'] == True`), call `fetch_facebook_posts(config)` inside a try‑except block.
   - If Facebook fetching raises any exception, catch it, log error, and continue with RSS entries only (do not stop the whole job).
   - Merge Facebook entries with RSS entries into a single list `all_entries`.
   - Add a `feed_url` field to each Facebook entry (value = Facebook page URL) to match RSS entry format.

2. Ensure backward compatibility:
   - If `facebook_source.json` does not exist or `enabled` is false, skip Facebook fetching entirely; job works as before.
   - If Facebook fetching returns empty list, treat as normal (no new posts).

3. Pass merged entries through existing pipeline:
   - `filter_new_entries` (duplicate detection via database)
   - `process_new_articles` (translation, summarization, Telegram posting)
   - No changes needed to these functions; they should handle the new entries transparently.

## Details

**Files:** 
- `news_bot.py` — modify `job()` function

**Dependencies:** Tasks 1 (configuration), 5 (fetch_facebook_posts)

**Edge cases:**
- `facebook_source.json` missing → skip Facebook, no error
- `facebook_source.json` malformed → catch `ValueError` from `load_config`, log error, skip Facebook
- `fetch_facebook_posts` returns empty list → merge empty list, no effect
- Facebook entries have duplicate links with RSS entries → duplicate detection should handle them
- Facebook fetching times out → catch `requests.exceptions.Timeout`, log, continue

**Implementation hints:**
- Wrap Facebook fetching in `try:` block before merging entries.
- Use existing logging (`logger.error`) for errors.
- Ensure `feed_url` is added before passing to `filter_new_entries` (duplicate detection may use feed_url as part of key).
- Consider extracting Facebook fetching into a helper function inside `news_bot.py` for clarity.
