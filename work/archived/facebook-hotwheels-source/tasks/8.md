# Task 8: Unit tests

## Required Skills

Перед выполнением задачи загрузи:

## Description

Write comprehensive unit tests for each function in `facebook_source.py` (configuration loading, RSS parsing, Graph API parsing, HTML parsing, keyword filtering, fallback orchestrator). Use pytest and mocking.

## What to do

1. Create a new test file `tests/test_facebook_source.py`.
2. For each function in `facebook_source.py`, write unit tests that cover:
   - **`load_config`**: valid config, missing file, malformed JSON, missing required fields, environment variable for token.
   - **`fetch_facebook_rss`**: successful RSS parsing, HTTP errors, malformed RSS, missing fields.
   - **`fetch_facebook_graph`**: successful Graph API response, invalid token, rate‑limiting (429), missing images, empty data.
   - **`fetch_facebook_html`**: successful HTML parsing, missing posts, missing fields, network errors, rate‑limiting.
   - **`filter_posts_by_keywords`**: keyword matching (case‑insensitive), no matches, empty keyword list, missing message field.
   - **`format_facebook_entry`**: mapping from RSS, Graph API, HTML sources, missing fields, default values.
   - **`fetch_facebook_posts`**: fallback order, skipping unavailable methods, keyword filtering, error handling, all methods fail.

3. Use pytest fixtures for common test data (e.g., sample RSS XML, Graph API JSON, HTML snippets).
4. Mock external HTTP requests using `responses` library or `unittest.mock.patch` on `requests.get`/`feedparser.parse`.
5. Ensure tests are isolated (no real network calls) and fast.
6. Aim for high coverage (>= 90% of `facebook_source.py`).
7. Run tests and verify they pass with the existing implementation (from tasks 1‑7).
