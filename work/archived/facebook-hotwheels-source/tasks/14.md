## Description

Deploy updated bot to production environment, verify logs.

## What to do

1. **Prepare deployment package**:
   - Ensure all changes are merged into the target branch (e.g., `main` or `dev`).
   - Update version if needed (e.g., `pyproject.toml` or `setup.py`).
   - Ensure `requirements.txt` includes any new dependencies (none expected).

2. **Deploy to production**:
   - Follow existing deployment process (e.g., Docker build/push, Kubernetes rollout, AWS Elastic Beanstalk, or simple `git pull` on server).
   - If using CI/CD, trigger deployment pipeline.
   - If manual, copy files to production server and restart the bot service.

3. **Verify deployment**:
   - Check that new code is running (e.g., `git log --oneline` on server, or Docker image tag).
   - Monitor logs for startup errors (Facebook config loading, missing environment variables).
   - Ensure the bot starts successfully and schedules jobs.

4. **Post‑deploy smoke test**:
   - Run a quick test to verify Facebook fetching works (optional, may be skipped to avoid unnecessary requests).
   - Alternatively, check that the bot processes RSS feeds as before (no regression).

5. **Update documentation** (if needed):
   - Add notes about Facebook configuration in deployment guide.
   - Document environment variable `FACEBOOK_ACCESS_TOKEN`.

6. **Log deployment outcome** in `work/facebook-hotwheels-source/logs/deploy/deploy.md`.
