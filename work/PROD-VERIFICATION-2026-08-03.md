## Шаг 1 — одна команда (30 секунд)

```
ssh root@45.90.216.165 "cd /root/hw-news && git pull && python3 scripts/prod_check.py"
```

**Это безопасно в любое время, включая окно публикаций 10:00–20:00 МСК.**
`git pull` обновляет только файлы на диске; работающий контейнер продолжает крутить
уже собранный образ, пересборки не происходит — то есть выкатки нет. Сам скрипт
(`scripts/prod_check.py`) открывает базу **только на чтение**, ничего не пишет, в
сеть не ходит и секретов не печатает. Проверено: читает корректно даже когда бот в
этот момент пишет в базу.

Скрипт закрывает все проверки по базе, которые были расписаны в четырёх старых
задачах: публикуется ли что-нибудь, не замолчал ли источник, не растёт ли очередь,
не залипла ли аварийная машина, прогрет ли дедуп.

**Присылайте вывод целиком.** Внизу он сам пишет итог одной строкой: «всё в
норме» / «есть на что посмотреть» / «есть проблемы».

### Что скрипт скажет и что это значит

| Строка | Что означает |
|---|---|
| `источник 't-hunted' молчит 14 дней` | фича `t-hunted-pt-source` не работает — главное, что проверяем |
| любой другой источник молчит | регрессия: добавление t-hunted что-то сломало |
| `окно дедупа ПУСТОЕ` | `cross-source-dedup` слепой, сравнивать не с чем → см. Шаг 3 |
| `в очереди: N (порог 50)` | фетчит быстрее, чем публикует (потолок 3 поста в день) |
| `outage_state = ping_2_sent` | залипла авария: статьи придерживаются, публикаций не будет |

## Шаг 2 — журнал контейнера (2 минуты)

Скрипт не читает логи, поэтому три команды отдельно. Тоже только чтение.

**2.1. Контейнер поднят и не перезапускается по кругу**

```
ssh root@45.90.216.165 "docker ps --filter name=hw-news-bot --format 'status={{.Status}}'"
```

Ждём `status=Up` и внятное время. `Restarting` или маленький аптайм — контейнер
падает, это важнее всего остального.

**2.2. Ошибки за сутки**

```
ssh root@45.90.216.165 "docker logs hw-news-bot --since 24h 2>&1 | grep -E 'ERROR|CRITICAL|Traceback' | tail -20"
```

Пусто — хорошо. `Temporary failure in name resolution` или `Network is
unreachable` — это сеть сервера, а не бот: та самая ложная тревога, что уже была
однажды принята за отказ Claude.

**2.3. Срабатывания дедупа за две недели**

```
ssh root@45.90.216.165 "docker logs hw-news-bot --since 336h 2>&1 | grep -oE '\[E01[456]\]' | sort | uniq -c"
```

- `[E014]` — нашёл дубль, прислал кнопку на ревью. Норма.
- `[E015]` — жёсткий блок. **Каждое срабатывание стоит глазами проверить:** после
  случая 28 июля, когда подборка «10 машинок месяца» вызвала ложный блок, важно
  убедиться, что не выброшена живая новость. Блок необратим — ссылка пиннится.
- `[E016]` — дедуп не смог посчитать, статья вышла. Единичные — норма.

Пустой вывод сам по себе не поломка (дублей могло не быть), но вместе с «окно
дедупа ПУСТОЕ» из Шага 1 подтверждает, что дедуп не работает.

## Шаг 3 — прогрев дедупа, ТОЛЬКО если Шаг 1 сказал «окно дедупа ПУСТОЕ»

**Это уже изменение. Строго вне окна 10:00–20:00 МСК.**

Сначала вхолостую, ничего не меняя:

```
ssh root@45.90.216.165 "docker exec hw-news-bot python3 backfill_fingerprints.py --dry-run --days 30"
```

Если вывод осмысленный — боевой запуск (около 5 минут):

```
ssh root@45.90.216.165 "docker exec hw-news-bot python3 backfill_fingerprints.py --days 30"
```

**Как читать итог.** `Errors: 0` — отлично. Единичные `403` от autoevolution —
известное поведение Cloudflare, допустимо. **Массовые 403 — остановиться и НЕ
перезапускать:** есть ловушка, когда неудачный массовый прогон против
ограничивающего источника оставляет «навсегда пустые» отпечатки. Окно всё равно
прогревается само за 7 дней обычной работы, так что ничего не делать — рабочий
вариант.

После прогона повторить Шаг 1: число с отпечатком должно стать больше нуля.

## Шаг 4 — глазами, в канале (10 минут)

Это то, что не проверяется никакой командой.

1. **Последние 5–10 постов.** Заголовок с эмодзи, хештег `#<источник> #news` не
   обрезан, карточка с крупной картинкой.
2. **Найти пост от t-hunted, открыть Instant View.** Главный риск источника:
   **португальские слова** в русском тексте (`compartilhar`, `marcadores`,
   `postado`) или английские куски. Если их нет — источник считаем проверенным.
3. **Тир редкости** — после правки 2 августа должно быть `ТХ` / `СТХ`, и **одна
   форма в пределах статьи**. Известная слабость: мини-модель не всегда держит
   единообразие. Разнобой — не поломка, а материал для правки промпта.
4. **Нет повторов одной машины** из разных источников за две недели — живая
   проверка дедупа, которую база показать не может.
5. **Нет рекламных хвостов и «подпишитесь»** в теле статей.
