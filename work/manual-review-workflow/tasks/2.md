# Task 2: `preview_renderer` module

## Required Skills

Перед стартом загрузи:
- `/skill:code-writing` — [~/.claude/skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Создаём новый чистый модуль `preview_renderer.py` в корне репозитория, экспортирующий единственную публичную функцию `render_html(nodes, title) -> str`. Она ходит по дереву узлов Telegraph (то же самое, что собирают `_build_content` / `_build_content_from_blocks` в `telegraph_publisher.py`) и превращает его в самодостаточный HTML-документ, который оператор открывает локально через `webbrowser.open(file://...)` из CLI `hw_review preview N` (см. Decision 1 tech-spec'a).

Зачем этот модуль существует отдельно:

- Tech-spec Decision 1 отказался от варианта «черновик на Telegra.ph для превью» в пользу локального HTML. Структурные проверки, которые оператор делает глазами (порядок абзацев, позиции изображений, обрамление subtitle, footer), идентичны на обоих рендерах; локальный HTML убирает ~40% поверхности фичи (нет `edit_page`, нет `preview_url`/`preview_path` churn, нет `cleanup-drafts`, нет риска изменения Telegra.ph API).
- Поскольку HTML открывается в браузере под `file://` origin, модуль ДОЛЖЕН защитить оператора от XSS при скомпрометированной up-stream-статье. Для этого в рендере жёстко зашиты три слоя защиты из Decision 1:
  1. **Allowlist тегов** — наследуется из того набора, который уже эмитит `telegraph_publisher`: `p / figure / img / figcaption / iframe / h3 / h4 / hr / i / b / a`. Неизвестные теги **тихо выбрасываются** (зеркалит поведение Telegra.ph-валидатора — см. код в `_build_content_from_blocks`).
  2. **Allowlist URL-схем** — атрибуты `src` у `img` и `iframe`, а также `href` у `a` обязаны матчиться регулярке `^(https?://)`. Любой другой префикс (`javascript:`, `data:`, `file:`, `vbscript:`, относительные пути) — атрибут выбрасывается целиком. Остальные атрибуты (`alt`, `title` и т.п., если вдруг появятся) передаются только после HTML-escape значения.
  3. **CSP meta-тег** в `<head>` — `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; img-src https:; frame-src https:; style-src 'unsafe-inline'">`. Второй эшелон защиты на случай, если что-то всё-таки просочилось через allowlists.

Escape всех текстовых значений (включая кириллицу в `ru_title` / `ru_paragraphs`) выполняется через `html.escape(..., quote=True)` — кириллица не-ASCII, её специально НЕ трогаем, но HTML-специальные символы (`<`, `>`, `&`, `"`, `'`) экранируются. Void-теги из набора (`img`, `hr`, `br`) отдаются в self-closing форме `<tag ...>` (в HTML5 слеш не обязателен, но и не запрещён — придерживаемся формы без слеша, как это делает браузер-парсер). Для читаемости документа добавляется минимальный inline `<style>` (body font / max-width / figure margins / img max-width / iframe aspect-ratio / hr) — `style-src 'unsafe-inline'` в CSP специально его разрешает.

Модуль — pure-function: никаких сайд-эффектов, никаких обращений к диску / сети / ENV. Запись на диск и открытие браузера — зона ответственности CLI `hw_review preview` (Task 7, Decision 1 path-guard).

## What to do

1. Создать новый модуль `preview_renderer.py` в корне репозитория (рядом с `telegraph_publisher.py`, `news_bot.py`, `mattel_news_source.py` — по уже сложившейся плоской конвенции проекта).
2. Экспортировать единственную публичную функцию `render_html(nodes: list, title: str) -> str`. Всё остальное — рекурсивный внутренний рендер узла, множества-константы allowlists — держать приватным (префикс `_`).
3. Определить две приватные константы на уровне модуля:
   - `_ALLOWED_TAGS = {'p', 'figure', 'img', 'figcaption', 'iframe', 'h3', 'h4', 'hr', 'i', 'b', 'a'}` — полный набор тегов, который эмитит `telegraph_publisher._build_content*`.
   - `_VOID_TAGS = {'img', 'hr', 'br'}` — теги, у которых нет закрывающей формы; `br` в списке на будущее, `telegraph_publisher` его сейчас не эмитит, но пусть allowlist перекрывает его на случай будущих блоков.
   - Allowlist URL-схем: `_URL_ATTR_TAGS = {'img': 'src', 'iframe': 'src', 'a': 'href'}` и regex `_SAFE_URL_RE = re.compile(r'^https?://', re.IGNORECASE)`.
4. В `render_html` собрать документ строкой/списком частей и `''.join(...)` в конце. Порядок обязательных секций `<head>`:
   - `<!DOCTYPE html>`
   - `<html>`, `<head>`
   - `<meta charset="utf-8">`
   - **CSP meta** (точный текст — см. Description пункт 3; ассертится тестами byte-for-byte).
   - `<title>{html.escape(title)}</title>`
   - Минимальный inline `<style>` для читаемости (body font/width, figure margins, img max-width, iframe aspect-ratio 16/9, hr).
   - Закрытие `<head>`, открытие `<body>`.
   - `<h1>{html.escape(title)}</h1>` — оператор сразу видит заголовок статьи.
   - Рекурсивный рендер каждого узла из `nodes` через `_render_node`.
   - Закрытие `</body></html>`.
5. Реализовать `_render_node(node)`:
   - Если `node` — строка: вернуть `html.escape(node, quote=True)`. Это обязательная ветка: во всех местах `telegraph_publisher._build_content*` листья (`"Источник: "`, `"💬 «{subtitle}»"`, текст абзацев) приходят как голые `str`.
   - Если `node` — dict:
     - Прочитать `tag = node.get('tag')`. Если `tag` НЕ в `_ALLOWED_TAGS` — вернуть пустую строку (тихий drop — зеркалит поведение Telegra.ph-валидатора; см. `code-research.md` §7, `post-format.md` «unknown tags are silently dropped»).
     - Собрать строку атрибутов из `node.get('attrs') or {}`. Для каждой пары `(k, v)`:
       - Если этот `tag` присутствует в `_URL_ATTR_TAGS` и `k` равен соответствующему URL-атрибуту (`src` для `img`/`iframe`, `href` для `a`): проверить `v` через `_SAFE_URL_RE.match`. Если не матчится — **атрибут целиком выбрасывается** (НЕ escape, НЕ сохранение). Если матчится — добавить `{k}="{html.escape(v, quote=True)}"`.
       - Для всех остальных атрибутов — просто escape значения через `html.escape(v, quote=True)` и добавить.
     - Если `tag` в `_VOID_TAGS` — вернуть `<{tag}{attr_str}>` (без закрывающего тега, без детей).
     - Иначе — рекурсивно рендерить детей из `node.get('children') or []`, склеить, вернуть `<{tag}{attr_str}>{inner}</{tag}>`.
   - Любой другой тип узла (ни str, ни dict) — вернуть пустую строку (защитная ветка; на практике дерево из `telegraph_publisher` такого не содержит).
6. Написать unit-тесты в `tests/test_preview_renderer.py` — см. секцию TDD Anchor. Следовать стилю проекта: модули тестов используют pytest (напр. `tests/test_telegraph_publisher.py`) или unittest.TestCase (напр. `tests/test_integration.py`). Для этого модуля берём **pytest**-стиль (как у `test_telegraph_publisher.py`, поскольку оба тестируют чистые функции без DB). Входные ноды моделировать вручную — НЕ вызывать `telegraph_publisher._build_content*` из тестов (это private API). Фикстуры делать минимальными, как в существующем `tests/test_telegraph_publisher.py`.
7. Убедиться, что модуль самодостаточен: единственные импорты — `html` (stdlib) и `re` (stdlib). Никаких `requirements.txt`-изменений.

**Edge cases:**

- Пустой `nodes=[]` → валидный документ с пустым `<body>` (после `<h1>`).
- Пустой `title=''` → `<title></title>` + `<h1></h1>` (не крашит, пустые элементы валидны).
- Пустой `attrs={}` или отсутствие ключа `attrs` → просто `<tag>` без атрибутов.
- Пустой `children=[]` или отсутствие ключа `children` у non-void тега → `<tag></tag>`.
- Узел-строка в середине `children` (как `"Источник: "` в футере из `_footer_nodes`) → escape через `html.escape`.
- `href` у `<a>` с `https://example.com/?q=<script>` — значение `<script>` экранируется внутри атрибута через `html.escape(v, quote=True)`, атрибут сохраняется (схема `https://` прошла).
- URL-атрибут без значения (`{'src': ''}`) — regex `^(https?://)` на пустой строке не матчится → атрибут выбрасывается.
- URL-атрибут в верхнем регистре схемы (`JAVASCRIPT:alert(1)`) — `re.IGNORECASE` флаг на `_SAFE_URL_RE` ловит case-variance для валидных схем; `javascript:` НЕ в allowlist, драмы нет, но важно что `HTTPS://...` тоже пройдёт.
- Неизвестный тип узла (число, None, list) — защитная ветка возвращает пустую строку; не крашим.
- Глубоко вложенные `children` (figure→children:[img, figcaption→children:[текст]]) — рекурсия без ограничения глубины (реальные деревья Telegra.ph плоские ~2–3 уровня, для нас это избыточно, но выглядит аккуратно).
- Теги-войды с `children` (`{'tag':'img','children':['ignored']}`) — `children` игнорируются (void-тег не имеет содержимого); тест `test_void_tags_self_close` этого случая явно не покрывает, но поведение естественное.

**Implementation hints:**

- Набор тегов и форма узла — строго те же, что в `_build_content`/`_build_content_from_blocks` (`telegraph_publisher.py:92-222`). Не изобретай новые теги — если их нет у эмиттера, их нет и у нас.
- `html.escape(value, quote=True)` — стандартный способ, покрывает `<`, `>`, `&`, `"`, `'`. НЕ используй ручную замену через `str.replace` — это классическая дыра.
- Для URL-проверки: `re.compile(r'^https?://', re.IGNORECASE).match(value)`. Не пиши regex, который позволит `https://evil.com javascript:alert(1)` — `^` якорь обязателен. Пробелы в начале URL рубит regex автоматически (нет ни `\s*`, ни `/s`).
- Константу `_CSP_META` положи как готовую полную строку `'<meta http-equiv="Content-Security-Policy" content="default-src \'none\'; img-src https:; frame-src https:; style-src \'unsafe-inline\'">'` — тест byte-compare поймает любую опечатку.
- В inline `<style>` держи минимум — не тащи шрифты с `https://fonts.googleapis.com` (CSP с `default-src 'none'` их заблокирует; плюс сеть из `file://` в оффлайн-сценариях не работает). Системные стеки (`-apple-system,sans-serif`) достаточно.
- Порядок атрибутов в выводе — по итерации dict в Python 3.7+ insertion-ordered. Полагайся на это в тестах (атрибуты `telegraph_publisher` всегда идут в одном порядке: сначала `src` у `img`/`iframe`, `href` у `a`).
- Используй `''.join(parts)` вместо последовательной конкатенации — и читаемее, и избегает квадратичных копирований.
- Для больших тестов параметризуй через `@pytest.mark.parametrize` — короче и покрытие виднее.
- Не импортируй `telegraph_publisher` из `preview_renderer.py` — модуль должен быть полностью автономен. Граф зависимостей: `preview_renderer` ← `hw_review` → `telegraph_publisher` (Task 4 добавит public wrapper).

**Security notes (от security-auditor):**

- XSS surface: `img src="javascript:..."`, `a href="javascript:..."`, `iframe src="javascript:..."` — закрыто URL-scheme allowlist.
- `data:` URL → можно встроить SVG с `<script>` — закрыто URL-scheme allowlist + CSP (`default-src 'none'`).
- CSP — defence-in-depth на случай пропуска в allowlist. Не полагайся только на CSP: современные баги парсинга CSP в старых браузерах позволяли обход.
- Тихий drop неизвестных тегов — не пиши warning-лог, **не раскрывай** содержимое (оно может быть атакующей пейлоадой).
- Не используй `Markup`, `safe`, `|safe` — никаких jinja-подобных опт-аутов. Только голые строки и `html.escape`.
