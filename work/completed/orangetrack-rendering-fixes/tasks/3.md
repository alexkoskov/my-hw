# Task 3: Publisher — link helper + bullet rendering + heading

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Bug 3 of `orangetrack-rendering-fixes`: the publisher does not render `<a href>` runs from `block.runs` metadata, so same-site orangetrack links inside paragraphs/headings/list_items disappear in the published Telegraph article. Bug 1 also needs a publisher branch: `list_item` blocks (added by Task 1) must render as `<p>• {text}</p>` with the bullet prepended **at the publisher level only**, immune to LLM stripping.

This task adds two helpers (`_render_paragraph_with_runs`, `_is_same_site`) to `telegraph_publisher.py` and rewires the block-rendering loop inside `_build_content_from_blocks` so paragraph, heading, and `list_item` blocks all flow through the helper. The helper iterates runs, filters to same-site ones, finds each run's text in `block.text` via case-sensitive `str.find`, sorts hits by start position, drops overlapping later spans (rendered as plain text within their original substring), and splits the text into segments — surviving spans become `<a>`-nodes, surrounding segments are plain string children. Defensive guards: `removeprefix("www.")` for safe www-stripping (NOT `lstrip` — character-set strip is exploitable by lookalike domains); strict scheme check (`http`/`https` only); empty/None run.text early-return; bullet-doubling guard on list_item; DoS bounds on text/runs length.

Implements user-spec AC2, AC6, AC7, AC8, AC9; tech-spec Decisions 1, 4, 5, 7, 9, 10. `preview_nodes` is **NOT** modified — it's a thin dispatcher that delegates to `_build_content_from_blocks` when `blocks` is non-empty; that delegate is the one that needs rewiring.

## What to do

1. **Add `_is_same_site(href, source_netloc)` predicate** to `telegraph_publisher.py` (module level, near `_build_content_from_blocks`).
   - Empty/falsy `href` or `source_netloc` → return False.
   - Wrap `urlparse(href)` in try/except; on exception log a single WARNING with truncated href (first ~80 chars) + `type(exc).__name__` and return False.
   - Require `parsed.scheme.lower() in ("http", "https")` — drops `mailto:`, `javascript:`, `data:`, etc.
   - Require non-empty `parsed.netloc`.
   - Compare `parsed.netloc.lower().removeprefix("www.")` against `source_netloc.lower().removeprefix("www.")` — equal → True. Use `removeprefix` (Python 3.9+) NOT `lstrip("www.")`.
   - The signature accepts the parsed/normalized source netloc so the caller computes it once per `_build_content_from_blocks` invocation; OR the helper accepts the full `source_url` and does its own urlparse — either choice is fine, document the chosen contract in the docstring.

2. **Add `_render_paragraph_with_runs(text, runs, source_url)` helper** to `telegraph_publisher.py`.
   - Returns a list of children suitable for unpacking into a `p(*)` or `heading(level, *)` call (interleaved strings and `<a>`-node dicts).
   - Empty/None `runs` OR empty/None `source_url` → return `[text]` (single-element list, no link processing). Decision 7.
   - DoS bounds (Decision 10): if `len(text) > 100000` OR `len(runs) > 100` → log a single WARNING (include text length and runs count, no full text dump) and return `[text]` (fall through to plain text).
   - Compute `source_netloc` once via `urlparse(source_url).netloc` (guard with try/except — on failure, return `[text]`).
   - Iterate `runs` in given order:
     - Skip if `run.get("href")` is falsy.
     - Skip if `_is_same_site(href, source_netloc)` is False.
     - Get `rt = run.get("text") or ""`. If `rt.strip() == ""` → skip BEFORE calling `find` (Decision 9 — guards against `"".find("")=0` zero-width wrap).
     - `start = text.find(rt)`. If `start == -1` → skip (run.text not in translated block.text — silently drop per AC8).
     - Record `(start, start + len(rt), href, rt)`.
   - Sort recorded spans by `start`.
   - Resolve overlaps (Decision 5 — first-wrap-wins): walk sorted spans; keep span only if `start >= previous_kept.end`; otherwise discard the later span (its substring stays in the text — when we rebuild segments below, the discarded substring naturally appears as plain text since we only split around kept spans).
   - Build children list by splitting `text` around kept spans:
     - Pre-segment text (`text[:span.start]`) → string child if non-empty.
     - The span itself → `{"tag": "a", "attrs": {"href": span.href}, "children": [span.rt]}` (use the actual run.text — equal to `text[start:end]` at the matched position by construction).
     - Tail after last span → string child if non-empty.
   - Return the children list.

3. **Modify the block-rendering loop in `_build_content_from_blocks`** (NOT `preview_nodes`):
   - **paragraph branch** — replace `nodes.append(p(block["text"]))` with: compute `children = _render_paragraph_with_runs(block["text"], block.get("runs") or [], source_url)`, then `nodes.append(p(*children))`.
   - **heading branch** — replace `nodes.append(heading(block.get("level", 3), block["text"]))` with: compute `children` via helper, then `nodes.append(heading(block.get("level", 3), *children))`. Note: this requires `heading()` to accept variadic children; the current closure takes a single `text` argument — extend it to `def heading(level, *children): ... "children": list(children)`.
   - **list_item branch** (new) — added after heading branch:
     - `raw = block["text"]`
     - Strip leading bullet/whitespace combinations: `stripped = raw.lstrip(" •\t\n")` (Decision 10 bullet-doubling guard — covers cases where LLM emits `"• Ferrari"` or `"  • Ferrari"`).
     - `children = _render_paragraph_with_runs(stripped, block.get("runs") or [], source_url)`.
     - `nodes.append(p("• ", *children))`.
   - lead/image/video branches: **unchanged**.

4. **Update the docstring of `_build_content_from_blocks`** — add `list_item` to documented block shapes; note that paragraph/heading/list_item now flow through `_render_paragraph_with_runs` for same-site link rendering.

5. **No changes to `preview_nodes`, `publish_article`, or `_build_content`** — the helper invocation is local to `_build_content_from_blocks`.

**Dependencies:**

- No new packages: `urllib.parse.urlparse` is stdlib; `logging.warning` already in use via module-level `logger`.

**Edge cases to handle:**
- `runs=None` (block didn't get `runs` key): `block.get("runs") or []` at the call sites.
- `run` dict missing `href` or `text`: `run.get("href")` / `run.get("text") or ""`.
- `source_url=None` or empty string: helper returns `[text]` directly.
- `source_url` malformed: try/except around `urlparse(source_url)` returns `[text]`.
- `run.text` contains regex meta-chars (`.`, `?`, `*`, `(`, `)`): `str.find` is literal, not regex — no escaping needed.
- `run.text` appears multiple times in `block.text`: only first occurrence wrapped (`str.find` returns first); subsequent occurrences remain as plain text (no second wrap because each run produces at most one span, and there's no second run for the same text unless it has a different href — see two-runs-same-href test).
- Two runs with identical `run.text` and identical `href` (defensive): first run produces span at first occurrence; second run produces span at first occurrence too — same span coordinates, overlap-resolution drops the duplicate (or first-wrap-wins keeps the first; result is identical because spans are identical).
- LLM emits `"• Ferrari"` for list_item: `lstrip(" •\t\n")` removes bullet+spaces; result `"Ferrari"`. NOTE: the `•` in `lstrip` arg is a single Unicode bullet (U+2022); make sure the file is saved as UTF-8 and the bullet character is exactly U+2022 (matches the prepend `"• "` which uses the same character).
- Bullet character must match between strip pattern and prepend literal — both use U+2022.

**Implementation hints:**
- Compute `source_netloc` once at the top of `_render_paragraph_with_runs` (after the no-runs/no-source-url early-return) — passing it into `_is_same_site` avoids re-parsing `source_url` on every run.
- Use `logger.warning(...)` (not `logger.warn`, deprecated) with parametrized format args (`logger.warning("…%s…", arg)`) to keep with project logging style.
- For overlap resolution: a simple loop is enough — `kept = []; for span in sorted_spans: if not kept or span.start >= kept[-1].end: kept.append(span)`. Linear-time, deterministic.
- The `<a>`-node format must mirror the existing local `a(href, text)` closure output: `{"tag": "a", "attrs": {"href": href}, "children": [text]}`.
- Don't introduce a regex dependency — `str.find` is sufficient and matches the tech-spec's chosen approach (Decision 6).
- Keep helpers free of any dependency on local closures inside `_build_content_from_blocks` — they live at module level so future tests can import them directly (and Task 5 imports them by name).
- Module-level helpers should be private (`_render_paragraph_with_runs`, `_is_same_site`) — leading underscore — matching the convention of `_build_content_from_blocks`, `_footer_nodes`, `_auto_marker_node`.
