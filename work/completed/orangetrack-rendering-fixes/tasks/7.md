## Description

Полный security-аудит фичи `orangetrack-rendering-fixes` по OWASP Top 10 после реализации Wave 1 + Wave 2. Аудит — read-only: читаем итоговый код в `orangetrack_source.py`, `_llm_common.py`, `telegraph_publisher.py` и тесты в `tests/test_orangetrack_source.py`, `tests/test_telegraph_publisher.py`, проверяем заявленные защитные механизмы и пишем отчёт в `logs/working/wave-3-security-audit.md`.

Главная цель — подтвердить, что новые хелперы (`_render_paragraph_with_runs`, `_is_same_site`) и расширения dispatch-логики не вносят новых уязвимостей при обработке RSS-контента из orangetrackdiecast.com:

- **XSS / HTML-injection:** `_render_paragraph_with_runs` строит Telegraph node-tree (dict-структуры), а не HTML-строки. Атрибуты и текст уходят в Telegraph API как поля JSON. Подтвердить, что нет точек, где RSS-текст склеивается в HTML/script-контекст.
- **Open-redirect / lookalike-domain bypass:** проверить, что `_is_same_site` использует `removeprefix("www.")` (точечное снятие префикса), а не `lstrip("www.")` (символьный strip — пропустит `wwwfake-orangetrackdiecast.com` и `worangetrackdiecast.com`).
- **Scheme injection:** убедиться, что `mailto:`, `javascript:`, `data:` отсекаются проверкой `urlparse(href).scheme.lower() in ("http", "https")`.
- **Malformed URL handling:** `urlparse` exception оборачивается в try/except, логируется WARNING с обрезанным href, функция возвращает False — никаких unhandled exceptions, никакой утечки полного href.
- **DoS bounds:** `len(block.text) > 100000` или `len(block.runs) > 100` → fall-through на plain text + WARNING.
- **Display-text vs href trust boundary:** документировать как known-limitation (не новая уязвимость — orangetrack source считается доверенным наравне с телом статьи; href уже находится в `<a href>` исходного HTML, бот только сохраняет его).

Категории OWASP, фокусные для этой фичи: A03 (Injection — XSS/URL injection), A04 (Insecure Design — trust boundary), A09 (Security Logging — что логируется при malformed input).

## Details

**Files (read-only audit):**
- `orangetrack_source.py` — проверить ветку `<li>` в `_walk`: использует ли существующий `_runs_from_tag` (не пересобирает HTML), `block.text` не содержит маркеров, нет конкатенации с пользовательским текстом в опасном контексте.
- `_llm_common.py` — `_PATCHED_TEXT_BLOCK_TYPES` расширен только новой константой; нет влияния на security-поверхность кроме того, что list_item-текст теперь патчится LLM-ответом (как и paragraph/heading — та же модель доверия).
- `telegraph_publisher.py` — основная security-поверхность:
  - `_is_same_site(href, source_netloc)`:
    - try/except вокруг `urlparse(href)`;
    - `scheme.lower() in ("http", "https")` — whitelist, не blacklist;
    - `netloc` непустой с обеих сторон;
    - `removeprefix("www.")` для нормализации — точечный, не character-class;
    - WARNING с truncated href при exception, return False.
  - `_render_paragraph_with_runs(text, runs, source_url)`:
    - empty/whitespace-only `run.text` пропускается ДО `str.find` (Decision 9);
    - overlapping spans → first-wrap-wins, второй run рендерится как plain text (не теряется);
    - возвращает list of node-dicts/strings — не HTML-строку.
  - `_build_content_from_blocks` block loop:
    - DoS bound: `len(block.text) > 100000` ИЛИ `len(block.runs) > 100` → fall-through + WARNING;
    - list_item: `lstrip(" ••\t")` (bullet-doubling guard) ДО `"• "` prepending.

**Dependencies:** depends on Task 4 (parser tests) and Task 5 (publisher tests) — нужны как референс для оценки security-coverage.

**Edge cases to verify in audit:**
- `source_url=""` + `run.href="mailto:x"` → empty netloc на обеих сторонах не должно матчиться (тест `test_empty_netloc_dropped_when_source_also_empty`).
- `run.href="https://wwwfake-orangetrackdiecast.com/x"` → `removeprefix` не зацепится (тест `test_lookalike_domain_not_matched_negative`).
- `run.href="javascript:alert(1)"` → отсекается scheme-чеком (тест `test_javascript_scheme_dropped`).
- Малформированный href → urlparse exception → caught + WARNING + False (тест `test_run_with_malformed_href_skipped`).
- 1MB block.text + 1000 runs → DoS bound срабатывает, plain text path (тесты `test_dos_bound_skips_helper_on_huge_text`, `test_dos_bound_skips_helper_on_too_many_runs`).
