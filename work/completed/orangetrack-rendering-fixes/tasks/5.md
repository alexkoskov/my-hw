## Description

Покрыть юнит-тестами новый помощник `_render_paragraph_with_runs`, предикат `_is_same_site` и изменения в `_build_content_from_blocks`, добавленные в Task 3. Тесты пишутся в `tests/test_telegraph_publisher.py` и закрепляют поведение для всех веток рендеринга текстовых блоков (paragraph, heading, list_item) с учётом same-site линков, защитных проверок схем URL, lookalike-доменов, регистра, регекс-метасимволов в `run.text`, перекрывающихся диапазонов, bullet-doubling guard и DoS-границ.

Эта задача — финальная сетка безопасности для Bug 3 (same-site link rendering) и list_item рендеринга. Integration-тест в Task 4 проверяет всю цепочку end-to-end, а здесь юнит-тесты пинят каждую логическую ветку помощника отдельно с EXACT children list assertions (не substring-проверки), что критично для предотвращения регрессий в стиле «случайно совпало по подстроке». DoS-тесты дополнительно используют `assertLogs`/`caplog`, чтобы убедиться, что fallback на plain text сопровождается WARNING-логом, а не молчаливым проглатыванием.

## TDD Anchor

Тесты добавляются в `tests/test_telegraph_publisher.py`. Имена точные — соответствуют тех-спеку.

**Same-site rendering (helper напрямую):**
- `tests/test_telegraph_publisher.py::test_render_paragraph_with_same_site_link` — block text="A B C", runs=[{"text": "B", "href": "https://orangetrackdiecast.com/x"}] → 3 children: "A ", `<a>B</a>`, " C".
- `tests/test_telegraph_publisher.py::test_render_paragraph_with_external_link_dropped` — external href → plain text only.
- `tests/test_telegraph_publisher.py::test_run_text_not_in_paragraph_text_dropped` — run.text не встречается в block.text → plain text.
- `tests/test_telegraph_publisher.py::test_run_text_repeated_first_only_wrapped` — block.text содержит run.text дважды → wrap только первого вхождения.
- `tests/test_telegraph_publisher.py::test_overlapping_runs_first_wins_second_appears_plain` — два перекрывающихся run → первый wrap в `<a>`, второй остаётся как plain text. EXACT children list assertion.
- `tests/test_telegraph_publisher.py::test_two_runs_same_href_independent_wrapping` — два run с одинаковым href, разный text → каждый wrap в собственное первое вхождение.
- `tests/test_telegraph_publisher.py::test_run_text_with_regex_meta_chars` — run.text содержит `.?*()` → `str.find` (не regex) корректно матчит.
- `tests/test_telegraph_publisher.py::test_run_with_empty_text_skipped` — run.text == "" → skip, no zero-width `<a>` at position 0.
- `tests/test_telegraph_publisher.py::test_run_with_none_href_skipped` — run.href is None → skip без падения.
- `tests/test_telegraph_publisher.py::test_run_with_malformed_href_skipped` — href "not a url://!!" → urlparse exception caught, run skipped.
- `tests/test_telegraph_publisher.py::test_no_runs_renders_plain_text` — параметризовано: runs=[] и runs=None → plain `<p>{text}</p>`.

**Schemes / domain edge cases:**
- `tests/test_telegraph_publisher.py::test_mailto_scheme_dropped` — href="mailto:admin@orangetrackdiecast.com" → dropped.
- `tests/test_telegraph_publisher.py::test_javascript_scheme_dropped` — href="javascript:alert(1)" → dropped.
- `tests/test_telegraph_publisher.py::test_empty_netloc_dropped_when_source_also_empty` — source_url="" + run.href="mailto:x" → not matched.
- `tests/test_telegraph_publisher.py::test_www_prefix_normalized_for_same_site` — обе стороны: www.orangetrack vs orangetrack.
- `tests/test_telegraph_publisher.py::test_lookalike_domain_not_matched_negative` — wwwfake-orangetrackdiecast.com → НЕ матчится (Decision 4 `removeprefix` precision).
- `tests/test_telegraph_publisher.py::test_case_sensitive_match_negative` — run.text "Mercedes", block.text "mercedes" → НЕ матчится.

**list_item rendering:**
- `tests/test_telegraph_publisher.py::test_list_item_renders_with_bullet_prefix` — type=list_item → first child "• ".
- `tests/test_telegraph_publisher.py::test_list_item_with_same_site_link_combines` — list_item с runs → "• " + link rendering.
- `tests/test_telegraph_publisher.py::test_list_item_strips_leading_bullet_in_text` — text="• Ferrari" → children ["• ", "Ferrari"], НЕ ["• ", "• Ferrari"] (Decision 10 bullet-doubling guard).

**Heading rendering:**
- `tests/test_telegraph_publisher.py::test_heading_block_renders_h3` — type=heading level=3 → `<h3>`.
- `tests/test_telegraph_publisher.py::test_heading_block_with_link_combines` — heading с runs → `<h3>` с inline `<a>`.

**DoS bounds (WARNING лог обязателен):**
- `tests/test_telegraph_publisher.py::test_dos_bound_skips_helper_on_huge_text` — block.text length > 100000 → fallback на plain text + WARNING лог (assertLogs/caplog).
- `tests/test_telegraph_publisher.py::test_dos_bound_skips_helper_on_too_many_runs` — len(runs) > 100 → fallback, WARNING лог.

**Dependencies:**

- pytest, pytest-mark.parametrize (стандартный), `caplog` фикстура (стандартная pytest) или `unittest.TestCase.assertLogs` для проверки WARNING.
- `logging` модуль — для перехвата WARNING (стандартная библиотека).

**Edge cases (закрываются тестами):**
- Empty `run.text` — Decision 9 (zero-width `<a>` не должен появляться).
- Malformed href — Decision 4 (urlparse исключение поймано, run skip).
- mailto/javascript scheme — Decision 4 (strict scheme check).
- Empty netloc на обеих сторонах — Decision 4 (degenerate match prevention).
- `www.` prefix normalization — Decision 4 (`removeprefix`, не `lstrip`).
- Lookalike-домен `wwwfake-...` — Decision 4 (`removeprefix` precision).
- Case-sensitive match — AC6 (НЕ нормализуем регистр).
- Регекс-метасимволы в `run.text` — `str.find` (не `re.search`), `.?*()` экранировать не нужно.
- Перекрывающиеся диапазоны — Decision 5 (first-wrap-wins, второй остаётся plain text).
- Bullet-doubling — Decision 10 (`block.text.lstrip(" •\t")` перед добавлением `"• "`).
- DoS-границы — Decision 10 (text > 100000 chars или runs > 100 → fallback + WARNING).

**Implementation hints:**
- Для проверки EXACT children используй `assert nodes[i]["children"] == ["A ", {...a-node dict...}, " C"]`. Не делай `assert "A " in str(nodes)` — это будет принято code-reviewer'ом как плохая практика.
- Для проверки `<a>` узла сравнивай полный dict: `{"tag": "a", "attrs": {"href": "https://orangetrackdiecast.com/x"}, "children": ["B"]}` (или ту структуру, которую возвращает helper после Task 3 — посмотреть фактическую сигнатуру).
- Для DoS-тестов: `with caplog.at_level(logging.WARNING):` либо `with self.assertLogs(level="WARNING") as cm:` (если стиль файла классовый). Затем `assert any("DoS" in r.message or "skipped" in r.message ... for r in caplog.records)` — формулировку WARNING-сообщения уточнить из реализации Task 3.
- Параметризация: `@pytest.mark.parametrize("runs", [[], None])` для `test_no_runs_renders_plain_text`.
- Для `test_overlapping_runs_first_wins_second_appears_plain` — собрать конкретный пример: block.text="ABCDE", run1={"text": "BCD", "href": ...}, run2={"text": "CDE", "href": ...} → ожидаем ["A", `<a>BCD</a>`, "E"] (не ["A", `<a>BCD</a>`, "CDE"]) — уточнить в Task 3 реализации, как именно "second appears plain" интерпретируется по отношению к перекрытию vs overflow.
- Для `test_two_runs_same_href_independent_wrapping` — block.text="X Y", run1={"text": "X", "href": "https://orangetrackdiecast.com/a"}, run2={"text": "Y", "href": "https://orangetrackdiecast.com/a"} → оба wrap независимо.
- Для smoke-проверки `_is_same_site` отдельно (если хочется dedicated тестов на предикат, не только на helper) — допустимо, но не обязательно: сценарии mailto/javascript/lookalike/www/empty уже покрывают предикат через end-to-end вызов helper.
