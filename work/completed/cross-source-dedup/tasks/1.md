## Description

Создаём ядро feature — новый модуль `model_extractor.py` в корне репозитория, который извлекает «отпечаток модели» (fingerprint) из тела статьи и считает similarity между двумя такими отпечатками. Это чистая stdlib-only функция (re + json + set), без I/O — mirroring shape `boilerplate_filter.py` (module docstring → compiled regex constants at module load → pure helper functions).

Модуль экспортирует:
- `extract_fingerprint(article: dict) -> dict[str, list[str]]` — возвращает `{'strict': [brand+model], 'brands': [brand-only]}` (Decision 5 shape).
- `similarity(fp_a, fp_b) -> float` — guarded two-level Jaccard per Decision 4 (AC6 empty-fp guard + AC8 1-token / brand-count guards + AC10 two-level max).

Лексикон зашит на module-уровне (~35 брендов, четыре tier'а — Decision 2), регекс компилируется один раз на загрузке модуля (singleton), ReDoS-safe — все квантификаторы bounded (Decision 3). Bренды с риском prose-collision (`BMW`, `AMC`, `Lotus`) — case-sensitive отдельной веткой.

Параллельно с модулем создаём:
- `tests/fixtures/cross_source_dedup_pairs.py` — 8 размеченных пар (4 duplicate + 4 non-duplicate) по code-research §14.F, включая реальную пару 2026-06-03 (Pair 1 — t-hunted PT ↔ autoevolution EN Car Culture Road Trip Mix), AC8-probes (Pair 5 — Subaru BRZ vs Subaru WRX) и 1-token guard (Pair 6).
- `tests/test_model_extractor.py` — `TestExtractFingerprint` (~10 кейсов), `TestSimilarity` (~8 кейсов), `test_calibration_accuracy` (≥7/8 floor) и must-pass `test_calibration_real_pair_must_pass` (Decision 13 split — Pair 1 ОБЯЗАН классифицироваться как block, чтобы load-bearing пример не «съел» бюджет ошибки общего accuracy теста).

Задача независимая (wave 1), её результаты потребляются Task 4 (wire dedup gate в `news_bot.job()`) и Task 5 (`backfill_fingerprints.py`).

1. Создать `model_extractor.py` в корне репозитория (top-level, рядом с `boilerplate_filter.py`):
   - Module docstring — что делает модуль, контракт `extract_fingerprint` и `similarity`, ссылка на decisions 2-4 в tech-spec.
   - Type alias `Fingerprint = dict[str, list[str]]`.
   - Module-level лексикон `_LEXICON` — 35 брендов из Decision 2 / code-research §14.A.2, alphabetically ordered для diff-readability.
   - Module-level compiled regex constants:
     - `_MODEL_AFTER_BRAND_RE` — case-insensitive, с optional year prefix `(?:(?:19|20)\d{2}\s{1,3})?`, branded alternation (включая multi-word `aston\s{1,2}martin`, `land\s{1,2}rover`, `range\s{1,2}rover` и алиасы `chevy|chevrolet`, `vw|volkswagen`, `mercedes(?:-benz)?`), optional model token `[A-Za-z0-9][A-Za-z0-9\-]{1,24}` (per §14.B.3).
     - `_UPPERCASE_BRANDS_RE` — отдельный compile БЕЗ `re.I` для `BMW|AMC|Lotus` (prose false-match защита per §14.A.3).
   - Pure helper `extract_fingerprint(article)`:
     - Читает `article['title']`, `article['subtitle']`, `article['paragraphs']` — конкатенирует в один текст.
     - Прогоняет оба регекса однопроходно.
     - Year prefix drop'ается из fingerprint (per user-spec — PT часто опускает год).
     - Canonical key normalization: aliases приводятся к canonical (`chevy → chevrolet`, `vw → volkswagen`, `mercedes-benz → mercedes`), brands lowercased.
     - Возвращает `{'strict': sorted(list(strict_set)), 'brands': sorted(list(brands_set))}`. Sorted — для детерминированности (JSON-stable, тестируемо).
     - Empty input → `{'strict': [], 'brands': []}` (не None).
   - Pure helper `similarity(a, b)` per Decision 4:
     ```
     if not a['strict'] or not b['strict']: return 0.0  # AC6
     if len(a['strict']) <= 1 or len(b['strict']) <= 1: return jaccard(strict_a, strict_b)  # AC8
     if len(a['brands']) < 2 or len(b['brands']) < 2: return jaccard(strict_a, strict_b)  # AC8
     return max(jaccard(strict_a, strict_b), jaccard(brands_a, brands_b))  # AC10
     ```
   - Internal `_jaccard(a: set, b: set) -> float` — pure helper, защита от ZeroDivisionError (empty union → 0.0).
   - NO I/O, NO logging внутри модуля. Pure functions.

- Многократные вхождения одного brand+model в body — дедуплицируем через set ДО sorted.

**Implementation hints:**
- Регекс компилируется ОДИН раз на module load — внутри функций НЕ вызываем `re.compile` (mirror boilerplate_filter.py:81 convention; cost ordering — code-research §14.J).
- Используем `re.finditer` для one-pass scan, не `re.findall` если нужны groups (`brand`, `model`).
