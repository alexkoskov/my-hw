## Что делаем
Добавляем парсинг страницы `https://corporate.mattel.com/news` с фильтром по Hot Wheels в список источников новостей бота. Бот извлекает только официальные анонсы Mattel, связанные с Hot Wheels, и публикует их в Telegram-канал.

## Зачем
Пользователи хотят получать **официальные анонсы от Mattel** (новые коллекции, туры, лимитированные выпуски), которые не всегда покрываются сторонними блогами. Эта фича добавляет первоисточник к текущим RSS-источникам.

## Как должно работать
1. Бот загружает HTML-страницу `https://corporate.mattel.com/news` раз в сутки.
2. Извлекает встроенный JSON (`__NEXT_DATA__`) с последними новостями (~7 записей).
3. Фильтрует записи: оставляет только те, где в `title` или `handle` встречается фраза `hot wheels` / `hot-wheels` (регистр не важен).
4. Для каждой подходящей записи формирует запись в формате, совместимом с существующим пайплайном: `title`, `link` (`corporate.mattel.com/news/{handle}`), `published` (дата), `summary`.
5. Записи проходят через стандартный пайплайн: проверка дубликатов по БД → перевод на русский → суммаризация → публикация в Telegram с хэштегами `#hotwheels #mattel`.

## Критерии приёмки
- [ ] Бот раз в сутки загружает `corporate.mattel.com/news`.
- [ ] Парсит JSON из `__NEXT_DATA__` без падения, если структура не изменилась.
- [ ] Фильтрует только Hot Wheels записи (по ключевым словам в title/handle).
- [ ] Формирует entries в унифицированном формате, совместимом с `process_new_articles`.
- [ ] Опубликованные посты в Telegram содержат ссылку на оригинал `corporate.mattel.com/news/{handle}`.
- [ ] При ошибке (сайт недоступен, структура изменилась) — уведомление администратору, остальные RSS-источники продолжают работу.
- [ ] Дубликаты не публикуются (сохранение link в БД).

## Ограничения
- Сайт Mattel отдаёт только 7 последних записей без пагинации. Hot Wheels посты встречаются редко (~1 в месяц).
- Структура `__NEXT_DATA__` на Next.js может измениться при редизайне Mattel — нужен fallback (уведомление админа).
- Требуется User-Agent, имитирующий браузер (без него возвращается 400).

## Риски
- **Риск 1:** Mattel изменит структуру JSON или переедет на другую платформу. **Митигация:** try-catch вокруг парсинга, уведомление админа, изоляция от других источников.
- **Риск 2:** Сайт добавит Cloudflare-защиту от скрапинга. **Митигация:** использовать корректный User-Agent; при 403 — деградация с уведомлением, без блокировки других источников.
- **Риск 3:** Ложные срабатывания фильтра (новость упоминает Hot Wheels вскользь). **Митигация:** проверять совпадение в `title` (основное поле) и `handle` (URL-слаг, более надёжен).

## Технические решения
- Мы решили парсить встроенный JSON из `__NEXT_DATA__`, а не рендерить страницу через Playwright — данные доступны прямо в HTML после загрузки.
- Мы решили фильтровать по подстроке `hot wheels` / `hot-wheels` (case-insensitive), потому что категории у Mattel слишком общие (`Brand News`, `Corporate News`).
- Мы решили сделать отдельный модуль `mattel_news_source.py`, а не расширять `feeds.json`, потому что парсинг HTML/JSON принципиально отличается от стандартного RSS.
- Мы решили не делать пагинацию — 7 последних записей достаточно при ежедневной проверке.

## Тестирование

**Unit-тесты:** делаются всегда.

**Интеграционные тесты:** делаем — с моком HTTP-запроса (сохранённый HTML-фикстур) проверяем полный пайплайн от загрузки до публикации в мок-Telegram.

**E2E тесты:** не делаем — из-за внешней зависимости от mattel.com. Проверка в production через мониторинг логов.

## Как проверить

### Агент проверяет

| Шаг | Инструмент | Ожидаемый результат |
|-----|-----------|-------------------|
| 1. Запустить unit-тесты парсинга с фикстурой HTML | pytest | Все тесты проходят, извлечены ожидаемые поля |
| 2. Запустить интеграционный тест с моком Telegram | pytest + unittest.mock | Мок получает корректное сообщение |
| 3. Сделать реальный запрос к `corporate.mattel.com/news` | curl/python | HTTP 200, в ответе есть `__NEXT_DATA__` |
| 4. Симулировать ошибку (500, изменённый HTML) | pytest | Уведомление админу отправлено, другие RSS-источники работают |

### Пользователь проверяет
- После деплоя убедиться, что в Telegram-канале появляются посты из Mattel с корректным переводом и ссылкой на оригинал.
- Убедиться, что не появляются посты без связи с Hot Wheels (Barbie, Masters of the Universe и т.п.).
