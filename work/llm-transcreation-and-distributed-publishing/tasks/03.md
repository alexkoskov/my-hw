# Task 3: Create `claude_transcreation.py` + tests

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Создаём новый модуль `claude_transcreation.py` — обёртку над Anthropic Python SDK, которая транскреирует одну статью через Claude API по тому же промпту (`ux-guidelines.md`), что использует оператор в `hw_review` сессиях. Это ядро auto-fallback пути после фичи: качество перевода выравнивается с manual-review, Google Translate остаётся только per-article fallback'ом и общим outage-fallback'ом.

Модуль реализует Decisions 5 (классификация SDK исключений на API-level vs per-article), 6 (system prompt = ux-guidelines.md verbatim + JSON envelope, model = Haiku 4.5, max_retries=2 default, без streaming), 8 (flat-path fallback при загрузке `ux-guidelines.md` с сервера) и 13 (`max_tokens=8000`, валидация длины `paragraphs`, defensive 4000-char truncation per paragraph).

Параллельно пишем `tests/test_claude_transcreation.py` (15 тестов с замоканным anthropic SDK — точный список см. TDD Anchor) — покрываем happy path, каждую ветку классификатора исключений, парс malformed JSON, schema-mismatch, emoji-prefix safety net, defensive paragraph truncation, prompt subdir/flat fallback. Тесты не делают реальных сетевых вызовов.

## What to do

1. Создать файл `claude_transcreation.py` в корне репо со следующими публичными элементами (контракт см. code-research §14.2 и Decision 13):
   - Константа `_PROMPT_PATH` — путь к `ux-guidelines.md` в сабдиректории `.claude/skills/project-knowledge/references/ux-guidelines.md` относительно `__file__`.
   - Кэш `_PROMPT_CACHE` — словарь с ключами `mtime` и `body`. Перезагружается при изменении mtime файла.
   - Класс `ClaudeTranscreationError(Exception)` — per-article ошибки (refuse, malformed JSON, schema mismatch).
   - Класс `ClaudeOutageError(Exception)` — API-level ошибки (network, 429, 5xx, auth, model-not-found).
   - Функция `_load_prompt(path=_PROMPT_PATH) -> str` — пробует subdir-путь, затем flat-fallback `os.path.join(os.path.dirname(__file__), 'ux-guidelines.md')` (Decision 8). На обоих путях miss → raise `FileNotFoundError`. Возвращает кэшированное тело по mtime; пустой файл → raise.
   - Функция `_build_system_prompt(prompt_body: str) -> str` — добавляет к телу `ux-guidelines.md` JSON envelope (см. code-research §14.3) после горизонтальной черты `\n\n---\n\n## Output format ...`.
   - Функция `_build_user_message(article: dict) -> str` — сериализует статью в JSON (`source_name`, `title`, `subtitle`, `paragraphs`, `blocks`).
   - Функция `_parse_response(text: str, expected_paragraph_count: int, expected_block_count: int) -> dict` — strip ```json``` fences, `json.loads`, валидация ключей (`title`, `alts` 2-3 шт., `subtitle`, `paragraphs` ровно `expected_paragraph_count`, опциональный `blocks` соответствующей длины). На любом mismatch → `ClaudeTranscreationError`.
   - Функция `_apply_emoji_safety_net(title: str) -> str` — если первый символ не один из `{🏆,🏎️,🚀,💎,🤝,📢,🚗,🔥}`, добавляет emoji по контентному regex (та же логика, что в legacy `transcreate_text(is_title=True)` в `news_bot.py:404-423`).
   - Функция `_truncate_paragraphs(paragraphs: list[str]) -> list[str]` — defensive cap 4000 символов per paragraph; при срабатывании пишет `logger.warning("paragraph truncated at 4000 chars")` (Decision 13).
   - Функция `_classify_exception(exc: Exception) -> Exception` — преобразует anthropic SDK исключения в `ClaudeOutageError` или `ClaudeTranscreationError` per Decision 5. API-level: `APIConnectionError`, `APITimeoutError`, `RateLimitError`, `InternalServerError`, `AuthenticationError`, `PermissionDeniedError`, `NotFoundError`. Per-article: `BadRequestError`, `UnprocessableEntityError`, `APIStatusError` (unrecognized) → `ClaudeTranscreationError`. **SDK exception hierarchy (verified против anthropic v0.45.2 source):** все эти 11 классов экспортируются из top-level `anthropic` package; `APIError` базовый, `APIStatusError` базовый для status-specific (4xx/5xx), `APIConnectionError`/`APITimeoutError` отдельно (timeout наследник connection). Если когда-нибудь SDK обновят и какой-то класс пропадёт — `_classify_exception` должна fail loudly при импорте, не silently dead code.
   - Функция `is_outage_error(exc: Exception) -> bool` — публичный classifier helper для caller'а (`_fallback_publish` в Wave 3 task 7).
   - Функция `is_per_article_error(exc: Exception) -> bool` — симметрично.
   - Функция `transcreate_via_claude(article: dict, *, prompt_path=_PROMPT_PATH, model=None, max_tokens=8000, timeout_s=60, client=None) -> dict` — главный публичный entry point:
     - `model` по умолчанию читается из `os.getenv('ANTHROPIC_MODEL', 'claude-haiku-4-5')`.
     - `client` — инжектируемый для тестов; по умолчанию singleton `anthropic.Anthropic()` (lazy-init на первом вызове, ENV-driven `ANTHROPIC_API_KEY`).
     - Загружает промпт через `_load_prompt(prompt_path)`, строит system + user messages.
     - Блокирующий API call (без streaming): `client.messages.create(model=..., max_tokens=8000, system=..., messages=[{role:'user', content:user_msg}])`. Default `max_retries=2` (SDK default).
     - Логирует на INFO: `input_tokens`, `output_tokens`, `latency_ms`, `model_version` после успеха (AC19, см. tech-spec).
     - Парсит response, применяет emoji safety net к `title`, truncate per paragraph defensively.
     - Возвращает dict per контракту.
     - На любое исключение SDK или внутри парсинга → `_classify_exception(exc)` raise.
   - Функция `health_check(client=None) -> bool` — короткий 10-token probe (`messages.create(max_tokens=10, ...)`); на `ClaudeOutageError` возвращает False, на success True. Используется `outage_state` recovery probe (Wave 2 task 5).

2. Создать `tests/test_claude_transcreation.py` (15 тестов; anthropic SDK замокан через `unittest.mock.MagicMock` с подменой `client.messages.create`):
   - **Happy path:** валидный JSON-ответ → возвращается dict с `title` (с emoji), `alts` (2-3), `subtitle`, `paragraphs` (длина = input). Token-логирование ассертится через `caplog`.
   - **`RateLimitError` (429)** → raise `ClaudeOutageError`.
   - **`AuthenticationError` (401)** → raise `ClaudeOutageError`.
   - **`APIConnectionError`** → raise `ClaudeOutageError`.
   - **`APITimeoutError`** → raise `ClaudeOutageError`.
   - **`InternalServerError` (5xx)** → raise `ClaudeOutageError`.
   - **`PermissionDeniedError` (403)** → raise `ClaudeOutageError`.
   - **`NotFoundError` (404, model)** → raise `ClaudeOutageError`.
   - **`BadRequestError` (400)** → raise `ClaudeTranscreationError`.
   - **`UnprocessableEntityError` (422)** → raise `ClaudeTranscreationError`.
   - **Malformed JSON** в ответе → raise `ClaudeTranscreationError`.
   - **Schema mismatch — wrong paragraph count** → raise `ClaudeTranscreationError`.
   - **Title без emoji prefix** → safety-net regex добавляет emoji (тестируем минимум 2 ветки content regex).
   - **Defensive truncation** — параграф длиной 5000 символов → обрезается до 4000, warning в логах.

**Edge cases:**
- `ux-guidelines.md` отсутствует на обоих путях → `FileNotFoundError` (downstream Decision 14 startup health check ловит это в `news_bot.main()`, не падая).
- `ux-guidelines.md` пустой файл → raise (treat as missing).
- Article с `blocks=None` (lamley/mattel) → user message содержит `"blocks": null`, response может не содержать ключа `blocks` → допускается.
- Article с `blocks=[...]` (autoevolution) → response должен содержать `blocks` той же длины и порядка типов; otherwise schema mismatch → `ClaudeTranscreationError`.
- Title уже с emoji prefix → safety net не дублирует.
- Response содержит ```json ...``` markdown fence → strip перед `json.loads`.
- `client=None` в тестах: НЕ default-creating real anthropic client; тесты ВСЕГДА передают mock.
- Module-level singleton `anthropic.Anthropic()` для production: lazy-init при первом вызове `transcreate_via_claude` без явного `client`. Без `ANTHROPIC_API_KEY` в env SDK сам поднимет `AuthenticationError` на первом call — это корректная outage-классификация.

**Implementation hints (patterns + invariants, не код):**

Это указатели на существующие паттерны и инварианты. Конкретные сигнатуры/реализации — на усмотрение разработчика, при условии, что соблюдены AC и Edge cases выше.

- **Lazy default client.** Модуль должен импортироваться без `ANTHROPIC_API_KEY` в env (нужно для test collection и для startup health checks Decision 14). Инвариант: реальный `anthropic.Anthropic()` создаётся только при первом фактическом вызове `transcreate_via_claude(...)` без явного `client=`. Паттерн singleton/lazy-init — стандартный.
- **Prompt cache by mtime.** Инвариант: повторный вызов `_load_prompt` без изменения файла читает кэш; при изменении mtime — перечитывает. Сравнение `os.path.getmtime(path)` с сохранённым значением — стандартный паттерн (есть аналоги в codebase для file-loaders).
- **JSON envelope как константа.** Не пересобирать строку envelope на каждый API-call — вынести в module-level константу.
- **JSON fence stripping.** Модель может вернуть голый JSON или JSON в ```` ```json ... ``` ```` fence. Инвариант: парсер должен принимать оба варианта без потери данных. Подход — strip опционального leading/trailing fence перед `json.loads`. Точную форму regex/string-match выбирает разработчик; ключевой инвариант покрывается тестами на оба формата ответа.
- **Emoji-prefix detection — footgun avoidance.** При проверке "начинается ли title с одного из 8 emoji", использовать `any(title.startswith(e) for e in EMOJIS)`, а не `title.startswith(EMOJIS)` через tuple. Причина: `str.startswith(tuple)` корректно работает для однокодпойнтных префиксов, но мульти-codepoint emoji вроде 🏎️ (U+1F3CE + U+FE0F) могут давать неинтуитивный результат при certain string normalizations. Явная итерация безопаснее и читаемее.
- **Emoji safety-net regex.** Если префикса нет, использовать ту же контентную regex-цепочку, что в legacy `transcreate_text(is_title=True)` в `news_bot.py:404-423` (HW-themed → 🏎️/🚀, championship → 🏆 и т.д.). Скопировать паттерны как есть; не пытаться их улучшать в этой задаче.
- **Token + latency logging.** На INFO уровне, одной строкой после успешного вызова, должны появиться: `model`, `input_tokens`, `output_tokens`, `latency_ms`. Точный формат на выбор разработчика; стиль — как существующие `logger.info(...)` вызовы в `news_bot.py` (key=value structured-ish). AC19 проверяет, что все 4 поля присутствуют — формат тестируется через `caplog` на substring match по именам полей, не по точной строке.
- **Catch-all для SDK исключений.** Базовый класс `anthropic.APIError` — единая точка ловли в `transcreate_via_claude`; внутри передаётся в `_classify_exception(exc)`, который и ветвится по конкретному подклассу.
- **Тесты: response mock shape.** Anthropic SDK возвращает объект с `.content[0].text` (text-block) и `.usage.input_tokens` / `.usage.output_tokens`. Fixture для mock-response должен воспроизводить именно эту форму. Для exception-тестов — `client.messages.create.side_effect = <ExceptionClass>(...)`.
- **Никакого prompt caching** (Decision 6) — слоты раз в 40 минут, TTL Anthropic cache 5 минут, выгоды нет.
- **Стиль кода:** следовать существующему `news_bot.py` (snake_case, docstrings, `logger = logging.getLogger(__name__)`).
