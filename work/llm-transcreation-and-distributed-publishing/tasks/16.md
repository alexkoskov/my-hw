## Verification Steps

### Automated

Аудит — read-only задача, сама не запускает кодовые тесты. Но в рамках audit может выполнять следующие проверки:

- `pytest --collect-only tests/ -q` → собирает список всех тестов; используется для подсчёта test count и проверки отсутствия collection errors (ссылок на удалённые символы).
- `grep -RE "_overflow_fast_track|_idle_fallback_publish|FALLBACK_THROTTLE_SECONDS|QUEUE_CAP|IDLE_TIMEOUT_HOURS|GRACE_WINDOW_HOURS" tests/` → ожидается empty output.
- `grep -RE "anthropic\.com|api\.telegram\.org|telegra\.ph|autoevolution\.com" tests/ | grep -v mock` → ожидается empty (или только в mock-фикстурах).
