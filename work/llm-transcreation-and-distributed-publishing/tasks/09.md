# Task 9: Delete legacy auto-publish code + env vars

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

После того как Wave 4 (Task 8) полностью переключил `job()` на новый distributed-publish loop с фиксированным cron в 12:00 МСК, окнами публикации, crash-loop guard'ом и Claude-primary translation, старый legacy-код auto-publish пути становится мёртвым весом. Эта задача физически удаляет его из `news_bot.py` и сопровождающих тестов.

Удаляются три бывших механизма и четыре env var'а (user-spec AC26):
- **`_overflow_fast_track`** (~210 LoC, news_bot.py:799–~880) — fast-track-evict pending rows, чтобы влезть в `QUEUE_CAP`. Новый алгоритм не имеет hard cap, излишек carry-over.
- **Inline idle-fallback в `job()` (steps 1a/1b, ~80 LoC, news_bot.py:1140–~1200)** — admin-ping для stale rows + auto-publish overdue. Заменён на детерминистический schedule из `compute_publish_slots`.
- **`FALLBACK_THROTTLE_SECONDS` throttle** (news_bot.py:70 + use sites :874, :962, :1194) — `time.sleep` между batch publish'ами. Новый distributed schedule сам разносит публикации min-interval=40 минут.
- **Env vars `QUEUE_CAP` (line 63), `IDLE_TIMEOUT_HOURS` (line 61), `GRACE_WINDOW_HOURS` (lines 62, 1153, 1180), `FALLBACK_THROTTLE_SECONDS` (line 70)** — больше не читаются, удаляются вместе с их `os.getenv` строками и комментариями.

Также удаляются companion тесты `tests/test_overflow.py` (полностью) и `tests/test_idle_fallback.py` (полностью), а из `tests/test_fallback_throttle.py` удаляются разделы Part A (throttle constant + TestOverflowThrottle + TestIdleFallbackThrottle) — оставляем только `TestTeaserAlwaysSingleLine` и `TestFallbackPublishPassesAutoMarkerToPublishArticle` (их предмет — auto_marker и one-line teaser, не throttle).

Цель: после задачи `pytest tests/ -q` зелёный, `grep -nE 'FALLBACK_THROTTLE_SECONDS|QUEUE_CAP|IDLE_TIMEOUT_HOURS|GRACE_WINDOW_HOURS|_overflow_fast_track|_idle_fallback' news_bot.py tests/` пустой (кроме истории git).
